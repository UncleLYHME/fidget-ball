# Security Policy

## Reporting A Vulnerability

Please do not open a public issue for security-sensitive reports.

Use GitHub private vulnerability reporting if it is enabled for the repository. Include:

- A short description of the issue.
- Steps to reproduce.
- The affected macOS version and app version or commit.
- Any relevant logs or crash output.

You should receive an initial response as soon as practical if private reporting is enabled and monitored.

## Scope

Security reports are most useful when they involve:

- macOS permission or launch-at-login behavior.
- Global shortcut handling.
- Packaging, signing, notarization, or update distribution.
- Unexpected persistence, file access, or process behavior.
